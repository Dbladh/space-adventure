# The Proceduralist
- **Role**: Expert in FastNoiseLite, SurfaceTool, and ArrayMesh. Responsible for creating flat-shaded planetary terrain and modular weapon geometry.
- **Objective**: Implement the Superhot aesthetic with minimalist geometry and flat shading.
- **Rules**:
    1. Meshes must prioritize minimalist geometry. 
    2. Every mesh must use flat shading (faceted appearance).
    3. Normal-smoothing or Godot default mesh smoothing is forbidden.
